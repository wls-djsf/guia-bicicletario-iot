PASSO 1

A Lógica: O que fica no Arduino e o que vai no ESP8266?

Você não perde nada do que já desenvolveu no Arduino! As duas placas trabalham juntas dividindo as tarefas:

🤖 1. No Arduino (Controle Físico)

Fica o seu código atual (CODIGOBIKE.ino), pois ele tem as 14 portas necessárias para:

  • Ler os 3 sensores ultrassônicos (pinos 2 a 7);
  • Acender os 6 LEDs verdes e vermelhos (pinos 8 a 13);
  • Mostrar no Display LCD I2C (pinos A4 e A5);
  • Novidade: Enviar "ocupadas,livres" (ex: 1,2) pelo pino A1 para o ESP8266.

📡 2. No ESP8266 (Internet / Wi-Fi)

Vai o código do servidor Web enviado pelo professor:

  • Conecta no Wi-Fi 2.4 GHz (ou roteador do seu celular);
  • Escuta o pino RX esperando o texto 1,2 vindo do Arduino;
  • Separa os dois números usando a vírgula ,;
  • Cria o site Bicicletário Inteligente que atualiza a cada 2 segundos.
🎓 Fundamentação Acadêmica desta Etapa (Clique para abrir/fechar) ▼

Arquitetura de Sistemas Embarcados Distribuídos via UART:

  • Limitação de I/O e Nível Lógico: Conforme o ESP8266EX Datasheet (ESPRESSIF SYSTEMS, 2023, Seção 1.4), o SoC opera em lógica CMOS de 3,3 V e possui número restrito de pinos GPIO. Já a maquete exige 14 pinos de I/O em lógica TTL de 5 V, atendidos nativamente pelo microcontrolador ATmega328P do Arduino (ALBUQUERQUE; ALEXANDRIA, 2015, p. 45-52).
  • Acoplamento Serial Assíncrono (UART): Segundo Oliveira (2017, Cap. 3) e Monk (2017, Cap. 11), a integração entre o Arduino e o coprocessador Wi-Fi é feita por comunicação serial assíncrona, transmitindo quadros de texto delimitados por vírgula e finalizados por quebra de linha (\n, ASCII 10).
PASSO 2

O que adicionar no Código do Arduino

Como os pinos digitais 2 a 13 do Arduino já estão ocupados pelos sensores e LEDs, usamos os pinos A0 (RX) e A1 (TX) para conversar com o ESP8266. São apenas 4 linhas adicionadas ao seu código:

1

No topo do código (junto com as bibliotecas):

Adicione #include <SoftwareSerial.h> para criar a porta de comunicação serial extra.

2

Logo abaixo do LiquidCrystal_I2C lcd(...):

Adicione SoftwareSerial espSerial(A0, A1); — isso define o pino A1 como transmissor (TX) para o ESP8266.

3

Dentro do void setup():

Adicione espSerial.begin(9600); na mesma velocidade (9600) que está no código do professor.

4

No final do void loop() (antes do delay(1000)):

Adicione espSerial.print(vagasOcupadas); espSerial.print(","); espSerial.println(vagasLivres); para enviar os dados a cada segundo.

📄 CODIGO_ARDUINO_BICICLETARIO.ino (Com citações acadêmicas nos comentários) 
//Bibliotecas encontradas no livro Automação e Instrumentação Industrial com Arduino Teoria e Projetos(Livro Fisico) 
//Pag. 201 (ALBUQUERQUE; ALEXANDRIA, 2015)
#include <Wire.h> //Biblioteca usada pelo LCD I2C
#include <LiquidCrystal_I2C.h> //Controlar o Display I2C

//Biblioteca SoftwareSerial para comunicação serial assíncrona (UART) com o módulo ESP8266
//Livro consultado: Programação com Arduino: Começando com Sketches de Simon Monk, 2. ed. Bookman, Cap. 11
#include <SoftwareSerial.h>

//Inicializa o LCD, 16x2 é o tamanho do display e o 0x27 é o endereço I2C tipo "IP"
LiquidCrystal_I2C lcd(0x27, 16, 2);

//Define os pinos A0 (RX) e A1 (TX) como porta serial secundária para enviar dados ao ESP8266.
//Segundo o livro Automação e Instrumentação Industrial com Arduino (Livro Fisico) Pag. 62,
//os pinos A0 a A5 (registrador PORTC do ATmega328P) operam nativamente como entradas e saídas digitais.
SoftwareSerial espSerial(A0, A1);

//Vetores pinos Gatilho e Retorno ou trig e echo das vagas(Sensores)
//Livro consultado Elementos de programação de Francisco A. C. Pinheiro Pag. 235 e 236(Biblioteca Online)
const int tVagas[] = {2, 4, 6};
const int eVagas[] = {3, 5, 7};

//Vetores LEDs
const int ledsVerdes[] = {8, 10, 12};
const int ledsVermelhos[] = {9, 11, 13};

//Livro Conceitos de linguagem de programação de Robert W. Sebesta Pag. 201(Biblioteca Online)
const int limite = 100;
const int totalVagas = 3;

void setup(){
  //Inicia comunicação serial com o ESP8266 em 9600 bps (MCROBERTS, 2015, Cap. 16; TANENBAUM, 2021, Cap. 2)
  espSerial.begin(9600);

  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("TESTE LCD OK");
  lcd.setCursor(0, 1);
  lcd.print("Funcionando OK");
  delay(2000);
  lcd.clear();

  //Livro consultado Automação e Instrumentação Industrial com Arduino (Livro Fisico) Pag. 160 e 175
  for (int i = 0; i < totalVagas; i++){
    pinMode(tVagas[i], OUTPUT);
    pinMode(eVagas[i], INPUT);
    pinMode(ledsVerdes[i], OUTPUT);
    pinMode(ledsVermelhos[i], OUTPUT);

    digitalWrite(ledsVerdes[i], LOW);
    digitalWrite(ledsVermelhos[i], LOW); 
  }
}

//Laço de repetição consultado em Elementos de programação de Francisco A. C. Pinheiro Pag. 171
void loop(){
  int vagasOcupadas = 0;
  for(int i = 0; i < totalVagas; i++){
    int distancia = medirDistancia(tVagas[i], eVagas[i]);
    if (distancia > 0 && distancia <= limite){
      vagasOcupadas++;
      digitalWrite(ledsVerdes[i], LOW);
      digitalWrite(ledsVermelhos[i], HIGH);
    } else {
      digitalWrite(ledsVerdes[i], HIGH);
      digitalWrite(ledsVermelhos[i], LOW);
    }
  }

  int vagasLivres = totalVagas - vagasOcupadas;

  lcd.setCursor(0, 0);
  lcd.print("Ocupadas: ");
  lcd.print(vagasOcupadas);
  lcd.print(" ");

  lcd.setCursor(0, 1);
  lcd.print("Livres: ");
  lcd.print(vagasLivres);
  lcd.print(" ");

  //Envia os dados via UART para o ESP8266 no formato "ocupadas,livres\n" (OLIVEIRA, 2017, Cap. 3)
  espSerial.print(vagasOcupadas);
  espSerial.print(",");
  espSerial.println(vagasLivres);

  delay(1000);
}

int medirDistancia(int pinT, int pinE){
  pinMode(pinT, OUTPUT);
  digitalWrite(pinT, LOW);
  delayMicroseconds(2);
  digitalWrite(pinT, HIGH);
  delayMicroseconds(10);
  digitalWrite(pinT, LOW);
  pinMode(pinE, INPUT);

  //Livro Automação e Instrumentação Industrial com Arduino (Livro fisico) Pag. 157
  long duracao = pulseIn(pinE, HIGH);
  //Física Conceitual de Paul G. Hewitt, 13. ed., Cap. 20 (Som)
  int distancia = duracao * 0.034 / 2;
  return distancia;
}
🎓 Fundamentação Acadêmica desta Etapa (Por que usar A0/A1 e 9600 bps?) ▼
  • Pinos A0 e A1 como Digitais: No microcontrolador ATmega328P, os pinos analógicos A0 a A5 pertencem ao registrador bidirecional PORTC e funcionam integralmente como entradas e saídas digitais (ALBUQUERQUE; ALEXANDRIA, 2015, p. 62).
  • Emulação de UART (SoftwareSerial): O Arduino Uno possui apenas uma UART de hardware (pinos 0 e 1, usada pelo cabo USB). A biblioteca SoftwareSerial cria uma segunda porta serial por temporização de software (MCROBERTS, 2015, Cap. 16; MONK, 2017, Cap. 11).
  • Sincronismo de Baud Rate (9600 bps): Como a comunicação UART é assíncrona (sem fio de clock), transmissor e receptor devem operar na mesma taxa de 9600 bits por segundo para evitar erros de enquadramento (TANENBAUM; WETHERALL, 2021, Cap. 2).
PASSO 3

Como Configurar e Gravar o Código no ESP8266

Para gravar o código do Wi-Fi no ESP8266, primeiro adicione o suporte à placa na Arduino IDE e depois grave o código abaixo (que já inclui a exibição do endereço IP no Monitor Serial).

1

Adicionar o pacote ESP8266 na Arduino IDE

Em Arquivo → Preferências, cole no campo URLs Adicionais para Gerenciadores de Placas:
http://arduino.esp8266.com/stable/package_esp8266com_index.json
Depois vá em Ferramentas → Placa → Gerenciador de Placas, busque por esp8266 e clique em Instalar.

2

Colocar o Nome e Senha do Wi-Fi (2.4 GHz)

Nas linhas ssid e password do código abaixo, coloque o Wi-Fi da sua casa ou o Roteador Wi-Fi (Hotspot) do seu celular (ótimo para o dia da apresentação na sala de aula!).

3

Como descobrir o IP para abrir o site?

Após gravar o código no ESP8266, abra o Monitor Serial (em 9600 baud). Ele mostrará a mensagem: Acesse no navegador: http://192.168.x.x. Basta digitar esse número no navegador do celular ou PC!

📄 CODIGO_ESP8266_WIFI.ino (Com exibição do IP e citações acadêmicas) 
//Bibliotecas oficiais para conectividade Wi-Fi (Padrão IEEE 802.11) e Servidor HTTP no ESP8266
//Livro consultado: Internet das Coisas com ESP8266, Arduino e Raspberry Pi de Sérgio de Oliveira (Novatec, 2017, Cap. 4 e 5)
#include <ESP8266WiFi.h>
#include <ESP8266WebServer.h>

//Credenciais da rede sem fio IEEE 802.11 b/g/n (2,4 GHz)
//Livro consultado: Redes de Computadores de Andrew S. Tanenbaum e David J. Wetherall (6. ed., Pearson, Cap. 4)
const char* ssid = "NOME_DO_SEU_WIFI";
const char* password = "SENHA_DO_SEU_WIFI";

//Instancia o servidor Web na porta TCP 80 (porta padrão do protocolo HTTP na Camada de Aplicação)
//Livro consultado: Redes de Computadores e a Internet de James F. Kurose e Keith W. Ross (8. ed., Bookman, Cap. 2)
ESP8266WebServer server(80);

//Variáveis do tipo cadeia de caracteres (String) para armazenar o estado das vagas (SEBESTA, 2018, p. 201-205)
String ocupadas = "0";
String livres = "3";

void handleRoot() {
  String html = "<html><head><meta charset='UTF-8'><meta http-equiv='refresh' content='2'></head>";
  html += "<body style='font-family: Arial; text-align: center; margin-top: 50px;'>";
  html += "<h1>Bicicletário Inteligente</h1>";
  html += "<h2 style='color: red;'>Vagas Ocupadas: " + ocupadas + "</h2>";
  html += "<h2 style='color: green;'>Vagas Livres: " + livres + "</h2>";
  html += "</body></html>";

  //Retorna código HTTP 200 (OK) e conteúdo MIME text/html (KUROSE; ROSS, 2021, Cap. 2)
  server.send(200, "text/html", html);
}

void setup() {
  //Inicia UART0 do ESP8266 em 9600 bps (ESP8266EX Datasheet, Espressif Systems, 2023, Seção 4.5)
  Serial.begin(9600);
  WiFi.begin(ssid, password);

  Serial.print("Conectando ao Wi-Fi");
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }

  //Exibe no Monitor Serial o endereço IPv4 atribuído via protocolo DHCP pelo roteador
  Serial.println("");
  Serial.println("Conectado com sucesso!");
  Serial.print("Acesse no navegador: http://");
  Serial.println(WiFi.localIP());

  server.on("/", handleRoot);
  server.begin();
}

void loop() {
  server.handleClient();

  //Lê os dados vindos do Arduino ("ocupadas,livres\n") e separa os valores na vírgula (SEBESTA, 2018, p. 205)
  if (Serial.available() > 0) {
    String dados = Serial.readStringUntil('\n');
    dados.trim();
    int virgula = dados.indexOf(',');
    if (virgula > 0) {
      ocupadas = dados.substring(0, virgula);
      livres = dados.substring(virgula + 1);
    }
  }
}
🎓 Fundamentação Acadêmica desta Etapa (Wi-Fi IEEE 802.11, HTTP e Substrings) ▼
  • Camada de Enlace IEEE 802.11 e DHCP: A função WiFi.begin() realiza a associação ao Ponto de Acesso em 2,4 GHz e obtém endereço IP dinâmico via protocolo DHCP (TANENBAUM; WETHERALL, 2021, Cap. 4 e 5).
  • Protocolo HTTP na Porta 80: Conforme Kurose e Ross (2021, Cap. 2), o servidor HTTP escuta conexões TCP na porta 80 e responde às requisições GET na rota "/" com o código de sucesso 200 OK e a página HTML com meta refresh de 2 segundos (OLIVEIRA, 2017, Cap. 5).
  • Análise Léxica de Subcadeias (Substring Slicing): Os métodos indexOf(',') e substring() particionam a cadeia de caracteres recebida em duas variáveis independentes (SEBESTA, 2018, p. 205).
PASSO 4

Ordem de Gravação e Guia de Soldagem dos Fios

⚠️ REGRA DE OURO (IMPORTANTE ANTES DE SOLDAR!):
Grave o código no ESP8266 e anote o IP ANTES de soldar o fio que vem do pino A1 do Arduino no pino RX do ESP8266! O pino RX também é usado pelo USB na hora de gravar o ESP8266; se o Arduino já estiver soldado enviando sinais nele, a gravação dará erro.

Você não precisa soldar todos os pinos do módulo ESP8266! Solde apenas os fios abaixo:

De onde sai (Arduino) Onde soldar (ESP8266) Função e Cuidado Prático
Pino A1 (TX do espSerial) Pino RX Envia os dados das vagas do Arduino para o ESP8266.
Dica de proteção: Coloque um resistor de 1 kΩ no caminho desse fio e um de 2 kΩ entre o RX e o GND para baixar de 5V para 3,3V.
GND GND Obrigatório: Une o terra das duas placas. Sem o GND interligado, os dados não passam de uma placa para a outra!
3.3V (ou 5V no VIN se for NodeMCU) VCC / 3V3 (+ pino EN/CH_PD) Se o seu ESP8266 for o módulo pequeno sem USB (ESP-01 ou ESP-12), ligue VCC e CH_PD/EN somente em 3.3V (nunca em 5V!).
🔧 Dica Prática para Soldar no Módulo Pequeno: Desencape apenas 2 mm da ponta do fio, coloque uma gotinha mínima de solda no fio e no contato do ESP8266 antes (estanhagem), e depois encoste um no outro com um toque rápido de 1 segundo do ferro de solda. No final, pingue cola quente na base dos fios para não quebrarem quando mexer na maquete!
🎓 Fundamentação Acadêmica desta Etapa (Lei do Divisor de Tensão e Soldagem) ▼
  • Cálculo do Divisor de Tensão Resistivo (BOYLESTAD, 2019, Cap. 5, p. 142):
    O Arduino emite nível lógico alto de $5\text{ V}$, enquanto o ESP8266 opera em $3,3\text{ V}$ (ESPRESSIF SYSTEMS, 2023, Seção 5.1). Pela equação do divisor de tensão em circuitos em série:
    V_RX = V_in × [ R2 / (R1 + R2) ] = 5 V × [ 2000 Ω / (1000 Ω + 2000 Ω) ] = 3,33 V
  • Equipontencialização de Referência (GND Comum): Segundo Boylestad (2019, Cap. 2), toda tensão elétrica é medida em relação a um nó de referência comum ($0\text{ V}$), tornando indispensável a união dos terminais GND.
  • Técnica de Estanhagem Prévia (BRAGA, 2018): A aplicação prévia de liga estanho-chumbo reduz o tempo de transferência térmica para menos de $1,5\text{ s}$, prevenindo delaminação dos pads metálicos SMD.
